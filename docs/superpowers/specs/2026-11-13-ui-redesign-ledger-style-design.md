# Redesign UI ให้เป็นสไตล์ระบบบัญชีโรงเรียน (Ledger)

วันที่: 2026-11-13
สถานะ: รออนุมัติ

## ทำไม

เจ้าของระบบอยากให้หน้าตาดูเป็นระบบบัญชี/การเงินของโรงเรียนที่เรียบ เป็นทางการ
และอ่านตัวเลขได้ง่าย เหมือนภาพอ้างอิง (sidebar ซ้าย, พื้นเทาอ่อน, การ์ดเส้นบาง,
ตารางมีแถบความคืบหน้า) โดยไม่แตะข้อมูลหรือตรรกะการทำงานเลย

## เป้าหมาย

- หน้าตาภาพรวมตรงแนวภาพอ้างอิง: เมนูซ้าย, การ์ดขอบบาง, ตัวเลขเด่น, ตารางอ่านง่าย
- ข้อมูลทั้งหมดเหมือนเดิม 100% (ไม่แก้ schema, API, ตัวเลข, ข้อความ)
- สีแยกหมวดงบยังเหมือนเดิม: งบอุดหนุน / งบพื้นที่นวัตกรรม / งบพัฒนาผู้เรียน / งบรายได้-อื่นๆ
- ใช้บนมือถือได้จริง (เมนูพับ), dark mode ยังใช้ได้, หน้าพิมพ์ A4 ยังขาวสะอาด

## สิ่งที่ไม่ทำ

- ไม่เปลี่ยนโครงข้อมูล, ไม่เพิ่ม/ลด field, ไม่แตะ `src/app/api/**`
- ไม่แก้สูตรคำนวณ, ไม่แก้เทมเพลต Word/PDF ราชการ (`ReportPrintView`, `docxExport`)
- ไม่เขียนข้อความการตลาดใหม่ แค่จัดหน้าตา
- ไม่เพิ่มฟีเจอร์ใหม่ (กราฟใหม่, ตัวกรองใหม่)

## ข้อจำกัด

- ฟอนต์ต้องรองรับไทย: คง Sarabun ไว้
- ผู้ใช้ปรับขนาดตัวอักษรได้ (16/18/19.2/21px) — layout ต้องไม่แตกที่ทุกขนาด
- มี CSS override สำหรับ dark mode ของหน้ารายงานอยู่แล้ว (`globals.css` `.dark .reports-scope`)
  ต้องปรับให้เข้ากับโทนใหม่ ไม่ทับซ้อนกันจนสีเพี้ยน
- ฟอร์มรายงานมี `id`/`htmlFor` ที่ใส่ไว้แล้ว ห้ามหลุด

## ทางเลือกที่พิจารณา

1. **เปลี่ยนแค่ token** (สี/ฟอนต์/มุมโค้ง) — เสี่ยงต่ำ แต่ไม่ได้ลุค sidebar ตามภาพ
2. **Sidebar เต็มตัวทุกขนาดจอ** — ตรงภาพที่สุด แต่มือถือเสียพื้นที่และต้องแก้ทุกหน้า
3. **Sidebar บนจอใหญ่ + เมนูบน/ลิ้นชักบนมือถือ** — ได้ลุคตามภาพ ยังใช้มือถือได้ ← เลือกทางนี้

### สี (dark)

canvas `#0B1220` · surface `#121B2B` · line `#1F2A3D` · ink `#E8EEF6` · body `#A9B6C7` · brand `#5B8FBF`
สีหมวดงบใน dark ใช้เฉดสว่างขึ้นของสีเดิม (เช่น `#7FB3DC`, `#A996CE`, `#7EC3AE`, `#D8B36B`)

### ตัวอักษร

- Sarabun น้ำหนัก 400/600/700
- สเกล: ตัวเลขสรุป 34–40px/700, หัวหน้า 26px/700, หัวการ์ด 17px/600, เนื้อหา 14px, หมายเหตุ 12px
- ตัวเลขการเงินใช้ `font-variant-numeric: tabular-nums` เพื่อให้หลักตรงกัน
- หัวตารางตัวพิมพ์ใหญ่间距 letter-spacing กว้างขึ้นเล็กน้อย (ตามภาพอ้างอิง)

### โครงหน้า

```
┌──────────┬────────────────────────────────────────────┐
│ ตรา+ชื่อ  │  page header: หัวข้อ + ทางขวา (ปุ่ม action)  │
│ ──────── │────────────────────────────────────────────│
│ ภาพรวม   │  ┌─ การ์ดสรุป 3 ใบ ──────────────────────┐  │
│ โครงการ  │  └───────────────────────────────────────┘  │
│ รายงาน   │  ┌─ กราฟ 2/3 ──────┬─ สรุป 1/3 ─────────┐  │
│ เอกสาร   │  └──────────────────┴────────────────────┘  │
│ ──────── │  ┌─ ตาราง/การ์ดรายการ ─────────────────┐   │
│ ตั้งค่า   │  └─────────────────────────────────────┘   │
│ ปีงบ ▾   │                                            │
│ ผู้ใช้    │                                            │
│ ออกจากระบบ│                                            │
└──────────┴────────────────────────────────────────────┘
```

เมนูมี 4 หน้าเท่าที่มีจริง (`/`, `/projects`, `/reports`, `/documents`) ไม่มีหน้า "งบประมาณ" แยก
— ตัวเลขงบอยู่ในหน้าแรก. "ตั้งค่า" เปิด `SettingsModal` เดิม. ตัวเลือกปีงบมีที่เดียวคือท้าย sidebar
(ไม่ทำซ้ำใน page header เพื่อไม่ให้มีตัวเลือกปีสองที่)

- Sidebar กว้าง 248px, พื้นขาว, เส้นขอบขวา 1px, โลโก้ + ชื่อระบบด้านบน, กลุ่มเมนู 2 กลุ่ม
  (งานหลัก / จัดการ), ด้านล่างเป็นปีงบ + โหมดผู้ใช้ + ออกจากระบบ
- เมนูที่เลือก: พื้น `brand-soft`, ตัวอักษร `brand`, แถบซ้าย 3px
- มือถือ (<1024px): แถบบนสูง 56px (โลโก้ย่อ + ปุ่มแฮมเบอร์เกอร์) เปิดลิ้นชักจากซ้าย
- เนื้อหา: กว้างสุด 1200px, ระยะขอบ 24px, ระยะระหว่างบล็อก 24px

### องค์ประกอบ

- การ์ด: `surface`, ขอบ 1px `line`, มุม 8px, เงาแทบไม่มี (`0 1px 2px rgba(15,27,45,.05)`)
- ตาราง: หัวตารางพื้นเทาอ่อน ตัวพิมพ์เล็ก, แถวคั่นเส้นบาง, ตัวเลขชิดขวา
- แถบความคืบหน้า: แท่งแบนสีเดียว (ไม่ไล่เฉด) สูง 6px, พื้นราง `#E3E8EF`
- ปุ่มหลัก: `brand` พื้นทึบ มุม 6px; ปุ่มรอง: พื้นขาว ขอบ `line`
- ป้ายสถานะ: ตัวอักษร 12px พื้นสีอ่อนของหมวดนั้น

### กราฟ (recharts)

- เส้นกริดสี `line`, แกนสี `muted` ขนาด 12
- แท่งมุมโค้ง 2px, สีตามหมวดเดิม (ฟ้า/ม่วง/เขียว/เหลือง) แต่ลดความสด
- tooltip พื้นขาว ขอบ `line` เงาเบา (dark: พื้น `surface`)
- ไม่มี animation ยาว: 300ms ตอนโหลดครั้งเดียว

### หน้าล็อกอิน

การ์ดกลางจอ พื้นขาว ขอบบาง ไม่มีเงาฟุ้ง, โลโก้โรงเรียนด้านบน, ปุ่มหลักสี brand,
ข้อความช่วยเหลือสี muted

### Dark mode

ทุกหน้าใช้ token ชุด dark; ยกเลิก override แบบเลือกสีทีละคลาสของหน้ารายงาน
ถ้าเปลี่ยนมาใช้ token ได้ครบ (ถ้าทำไม่ได้ครบ ให้คง override เดิมไว้แล้วปรับค่าให้ตรงโทน)

### หน้าพิมพ์ A4

ไม่แตะ `ReportPrintView`, คง `print-page` พื้นขาว; sidebar/topbar ซ่อนด้วย `print:hidden`

## สิ่งที่เหลือให้ผู้สร้างตัดสินใจ

- จะแยก token เป็น Tailwind theme หรือ CSS variables (แนะนำ CSS variables + Tailwind extend)
- จะแยก `StatCard`, `DataTable` เป็นคอมโพเนนต์ใหม่หรือเขียนในแต่ละหน้า
- ลำดับการย้ายหน้า (แนะนำ: shell → แดชบอร์ด → โครงการ → รายงาน → เอกสาร → ล็อกอิน)

## เกณฑ์ตรวจรับ

1. 4 หน้า + ล็อกอิน เปิดได้ ไม่มี error ใน console
2. เทียบ `GET /api/data` ก่อน/หลัง: ข้อมูลเท่ากันทุก byte (ไม่มีการเขียนข้อมูล)
3. dark mode: ไม่มีตัวอักษรกลืนพื้นหลัง, ตารางอ่านได้
4. มือถือ 390px: ไม่มี scroll แนวนอน, เมนูเปิด/ปิดได้
5. หน้าตัวอย่างพิมพ์ PDF ยังเป็นกระดาษขาว A4
6. `npm run verify` ผ่าน (tsc + build)

## คำตอบจาก builder check (ตัดสินแล้ว)

**ภาพอ้างอิง:** เก็บไว้ที่ `shots/reference-ledger.png` ใช้เทียบตอนจบงาน

**โมดัลและ Footer:** อยู่ในขอบเขต — จัดให้เข้าชุดด้วย token (มุม 8px, ขอบ `line`, ปุ่ม `brand`)
ไม่เปลี่ยนโครงสร้างหรือฟิลด์ ครอบคลุม `ActivityModal`, `ExpenseModal`, `ProjectModal`,
`DocumentModal`, `SettingsModal`, `Footer`

**รายการหลักยังเป็นการ์ด ไม่แปลงเป็นตาราง:** การ์ดกิจกรรม/โครงการมีการกางรายละเอียด

ส่วนตารางจริง (ค่าใช้จ่าย, รายการรายงาน) ใช้ `.table-base` และเพิ่มแถบความคืบหน้าเฉพาะ

**ตัวควบคุมปีงบ/ผู้ใช้:** อยู่ท้าย sidebar ที่เดียว (ปฏิทิน + ชื่อปี + บทบาท + ตั้งค่า + ออกจากระบบ)
บนมือถือ: แถบบนมีแฮมเบอร์เกอร์ + ชื่อปี (อ่านอย่างเดียว) ลิ้นชักมีตัวควบคุมจริงทั้งหมด

**PIN modal:** เอาออก — ซ้ำซ้อนกับ role จาก session แล้ว (เดิมครูเดา PIN เพื่อเปิดโหมดแก้ไข
แต่เซิร์ฟเวอร์ปฏิเสธอยู่ดี) แทนด้วยป้ายบทบาท + สวิตช์โหมดแก้ไขที่เห็นเฉพาะแอดมิน

**แอนิเมชัน:** ตัด shimmer / ping / hover-lift ออกให้เข้าลุคระบบบัญชี คง `AnimatedCounter`
